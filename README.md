            <p>HIKER PRO ("App", "we", "us") prioritizes user privacy. This Privacy Policy explains what information we collect, how we use it, and your rights.</p>

            <h2>2. Information We Collect</h2>
            
            <h3>2.1 Location Data</h3>
            <ul>
                <li><strong>Precise Location:</strong> Real-time location via GPS, GLONASS, Galileo, BeiDou, QZSS</li>
                <li><strong>Route History:</strong> Tracking paths and timestamps</li>
                <li><strong>Altitude Data:</strong> Elevation changes during hiking</li>
            </ul>
            <p><strong>Important:</strong> All location data is stored locally on your device and is NOT transmitted to external servers.</p>

            <h3>2.2 Device Information</h3>
            <ul>
                <li>Device model and OS version</li>
                <li>App version</li>
                <li>Crash and error logs (for app improvement)</li>
            </ul>

            <h3>2.3 Information We Do NOT Collect</h3>
            <ul>
                <li>Personal identifiers (name, email, phone)</li>
                <li>Payment information</li>
                <li>Contacts, photos, messages</li>
            </ul>

            <h2>3. How We Use Information</h2>
            <ul>
                <li><strong>Core Features:</strong> Real-time tracking, route recording, map display</li>
                <li><strong>App Improvement:</strong> Error analysis and bug fixes</li>
                <li><strong>Safety Features:</strong> Emergency location sharing (with explicit user consent only)</li>
            </ul>

            <h2>4. Data Storage and Security</h2>
            
            <h3>4.1 Local Storage</h3>
            <p>All location and route data is stored only on your device. We do NOT store or transmit your location to our servers.</p>

            <h3>4.2 Security Measures</h3>
            <ul>
                <li>Device storage encryption</li>
                <li>Android system security compliance</li>
                <li>Unauthorized access prevention</li>
            </ul>

            <h3>5.2 No Other Third Parties</h3>
            <p>We do NOT use advertising networks, analytics tools, or social media plugins.</p>

            <h2>6. Information Sharing</h2>
            <p>We do NOT share, sell, or rent your personal information. Exceptions:</p>
            <ul>
                <li><strong>User Consent:</strong> Emergency location sharing feature</li>
                <li><strong>Legal Requirements:</strong> Court orders or legal processes</li>
            </ul>
